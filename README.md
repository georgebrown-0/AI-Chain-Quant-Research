# AI Value Chain Arbitrage Quant Researcher Tools
Basic set of pair trading algorithms and models for the AI Value Chain Arbitrage project.  
Deployed GUI with Streamlit and visualised graphing with plotly.  
https://ai-chain.streamlit.app/  
- Yfinance data extraction for pair tickers
- Cointegration Testing
- Hedge Ratio
- Backtesting with z-scoring
